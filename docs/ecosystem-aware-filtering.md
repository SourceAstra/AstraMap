# AstraMap 生态感知过滤系统

**文档版本**: v0.3  
**更新日期**: 2026-07-16  
**作者**: AstraMap Team

---

## 1. 设计目标

索引过滤从「手动配置」进化为「零配置开箱即用」：

1. **自动识别工程生态**：扫描项目目录，根据 `go.mod`/`package.json`/`Cargo.toml` 等标记文件自动判断项目类型
2. **内置通用排除规则**：覆盖 VCS 元数据、第三方依赖、缓存、OS 垃圾、压缩文件、生成源码、二进制文件等 40+ 条规则
3. **结构化过滤报告**：`amap index` 输出按规则类型分组的排除报告，过滤行为完全透明
4. **用户可覆盖**：通过 `advanced.forceInclude` 强制包含被内置规则排除的文件

## 4. 过滤评估引擎

### 4.1 四级优先级

```
1. 内置规则（含生态感知动态规则）
   └── forceInclude 可覆盖 Overridable 规则
2. 隐藏路径（. 开头的目录/文件）
   └── forceInclude 可覆盖
3. 用户 Include（白名单模式）
4. 用户 Exclude
```

### 4.2 评估结果结构

```go
type FileIndexPlan struct {
    Path       string      // 相对路径
    Indexed    bool        // 是否索引
    RuleID     string      // 命中规则 ID
    Kind       ExcludeKind // 排除类型
    Reason     string      // 排除原因描述
    Overridden bool        // 是否被 forceInclude 覆盖
}
```

## 5. 配置格式

### 5.1 新版配置（v0.3）

```yaml
# AstraMap index filter config.
# Built-in rules automatically exclude: hidden paths, VCS metadata,
# dependencies, build artifacts, generated code, caches, and binaries.
# You only need to configure project-specific patterns.

index:
  languages:
    - go
    - typescript
  # include:
  #   - "src/**"
  # exclude:
  #   - "examples/legacy/**"
  # advanced:
  #   forceInclude:
  #     - "src/.domain/**"
```

### 5.2 向后兼容

旧配置中的 `scipExclude`/`treeSitterExclude` 自动合并到 `Exclude`：

```go
case "scipexclude", "treesitterexclude":
    // 向后兼容：合并到 Exclude
    filter.Exclude = append(filter.Exclude, normalizeFilterPath(value))
```
